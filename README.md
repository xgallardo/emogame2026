# EMOGAME 2026

A fan-made, **non-profit** homage to *Emogame* by **Jason Oda** (2008).

Kyle was emo in 2008. Now he's 34, works in an office in the Midwest, and Flash is dead. A prologue, five acts and an epilogue to save the game he loved.

## Play

- Open `index.html` in a browser (a double click works).
- To play it online, enable **GitHub Pages** in the repository settings (Settings → Pages → branch `main`, folder `/`).

### Controls
Arrows: walk · Up: jump · Space: throw a record · Shift/Ctrl: throw up · Enter: special · 1–7: switch character · Q: iPod shuffle · H: help · M: music

## The original

The original *Emogame 2* is preserved by the Internet Archive and runs in the browser with Ruffle:
https://web.archive.org/web/20080730171129/http://emogame.com/emogame2/index.html

In the epilogue, clicking Kyle's monitor opens it.
